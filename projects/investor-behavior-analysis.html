Investor Behavior Analysis using Deep Learning

2024–2025 · Supervisor: Dr. Ashish Vazirani

Developed an unsupervised multimodal model for investor emotions and decision-making patterns in Shark Tank videos.

  • Combined facial-expression recognition, RoBERTa transcript analysis, and tabular neural networks.
  • Used cross-modal attention to model investor behaviour.
  • Generated time-series investment-likelihood scores for each second of a pitch.
