OUR: MRI Motion Correction using Deep Learning Models

2024–2025 · Supervisor: Dr. Saurabh Janardan Shigwan

Developing deep learning models to correct MRI motion artifacts in real time using k-space data.

  • Exploring regression techniques and CNNs to improve motion estimation.
  • Using image processing and computer vision alongside deep learning.
  • Aiming to improve image quality and reduce re-scanning.
